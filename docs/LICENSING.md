# Licensing status

No open-source license has been applied to this repository yet. A public GitHub
repository does not by itself grant permission to reuse, modify, or redistribute
the code.

Before adding an MIT, Apache-2.0, or other license, every relevant team member must
confirm that the team owns the code and agrees to the chosen terms. The following
materials also need separate treatment:

- the EXIST dataset, which is not redistributed here;
- third-party model weights and generated caches;
- the final report and project figures, if their authors want terms different from
  the code license.

Once ownership and consent are confirmed, the recommended repository change is a
root `LICENSE` covering original code plus a short notice listing excluded external
assets. Until then, the absence of a license is intentional rather than accidental.
